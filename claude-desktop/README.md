# Claude Desktop + CovaSyn

Add the snippet below to your Claude Desktop configuration file.

**macOS path:** `~/Library/Application Support/Claude/claude_desktop_config.json`
**Windows path:** `%APPDATA%\Claude\claude_desktop_config.json`

After saving, restart Claude Desktop. CovaSyn tools will appear in the tool picker.

## Snippet

See [`claude_desktop_config.json`](./claude_desktop_config.json).

## Get an API key

[covasyn.com/en/pricing →](https://www.covasyn.com/en/pricing) — Free tier with 100 credits/week works for evaluation.
