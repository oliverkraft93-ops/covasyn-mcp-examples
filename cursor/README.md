# Cursor IDE + CovaSyn

Add to `.cursor/mcp.json` in your project root or to the global Cursor MCP config.

After adding, restart Cursor and accept the tool-permission prompt the first time you invoke a CovaSyn tool.

## Snippet

See [`.cursor-mcp.json`](./.cursor-mcp.json).

## Tip

Cursor auto-discovers tool documentation from MCP. Once connected, use `/` in chat to surface CovaSyn tools by name.
