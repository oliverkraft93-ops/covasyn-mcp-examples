# Contributing

Thanks for considering a contribution to covasyn-mcp-examples.

## What we accept

- Additional client integrations (LangChain, LlamaIndex, AutoGen, CrewAI, etc.)
- Improved snippets for existing clients
- Real-world workflow examples (with `# illustrative` notes if not run against live CovaSyn)
- Documentation improvements

## What we don't accept

- PRs that require changes to CovaSyn server code (we maintain that separately)
- Examples that hardcode credentials
- Submissions of competitive vendor configurations dressed as CovaSyn

## How

1. Fork → branch → commit → PR
2. Include a 1–2 sentence description in the PR body
3. If your example fetches data from CovaSyn, mark it `# requires CovaSyn API key` and link to the pricing page
